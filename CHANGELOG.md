# Changelog

This project has not established dated releases. The entries below summarize completed project milestones without assigning release dates.

## Completed Capabilities

### Added

- React/Vite frontend and FastAPI backend with MySQL persistence and Alembic migrations.
- User registration, login, JWT-protected operations, dataset management, and ownership checks.
- CSV, XLSX, TXT, DOCX, and PDF ingestion for supported structured tabular content.
- Dataset profiling, role detection, statistics, relationships, quality analysis, dashboards, and automatic insights.
- Dataset-driven exploration capabilities, recommendations, filtering, aggregation, summaries, and adaptive visualizations.
- Groq-backed dataset chat, exploration-aware context, structured reports, and report download.
- Light/dark theme, responsive workspace, production-oriented configuration validation, and upload/resource safeguards.

### Improved

- Bounded AI context and validated report response structure.
- Safer provider error mapping, upload handling, and account-scoped dataset access.
- Lazy loading for authenticated analytics routes and chart code.

### Security

- Password hashing, JWT validation, ownership validation, upload validation, secret separation, and production CORS/config checks.

### Performance

- Bounded exploration outputs and AI context; database connection health settings and dataset upload size controls.

### Documentation

- Phase 9 project, architecture, API, AI, deployment, testing, demo, limitations, and contribution documentation.
