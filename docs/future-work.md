- Additional file formats and configurable worksheet selection/combination.
- Background processing for large uploads and long-running analysis.
- Cloud object storage with managed retention and backup policies.
- Additional AI providers and provider failover.
- Scheduled reports, report history, and richer export formats.
- Advanced predictive modeling and broader statistical methods.
- Collaboration and shared dataset permissions.
